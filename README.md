# Soul Knight Clone

Клон популярной roguelike-игры Soul Knight, разработанный на C++ с использованием библиотеки SFML. Проект демонстрирует уверенное владение паттернами проектирования (в частности, паттерном State для управления состояниями игры), работу с игровой логикой, процедурной генерацией уровней и реализацией искусственного интеллекта противников.

## Особенности проекта
* **Архитектура:** Использование паттерна **State** (состояния Menu, Playing, Pause, End) для чистой и масштабируемой логики переключения экранов.
* **Генерация карт:** Логика сеточного построения (Grid-based map) с расстановкой препятствий, дверей и лута.
* **Игровые механики:**
    * Свободное передвижение и стрельба (Top-down shooter).
    * Смена и подбор различного оружия (Пистолет, SMG, Автомат).
    * Враги с разными паттернами поведения (ближний бой, стрельба).
    * Многофазный босс с уникальными атаками (Аура, лучи, викторина).
* **Сборка:** Проект легко собирается с помощью **CMake**.

## Технологии
* **Язык:** C++17
* **Библиотека:** SFML 3 (Graphics, Window, System, Audio)
* **Сборка:** CMake

## Как запустить?

В репозитории **отсутствует** собранный `.exe` файл (исполняемый файл). Это стандартная практика (не хранить бинарники в Git), чтобы репозиторий оставался легковесным, кроссплатформенным и безопасным.

Чтобы запустить игру, ее необходимо собрать из исходного кода.

### Инструкция по сборке (Windows, Linux, macOS)
1. Убедитесь, что у вас установлен **CMake** и компилятор C++ (например, MinGW, MSVC для Windows или GCC/Clang для Linux).
2. Установите библиотеку **SFML 3.x**. Если вы на Windows, обновите путь к SFML в файле `CMakeLists.txt` (переменная `SFML_DIR`).
3. Сборка через консоль:
   ```bash
   mkdir build
   cd build
   cmake ..
   cmake --build .
   ```
4. После успешной сборки запустите исполняемый файл `SoulKnightClone` (или `.exe` на Windows), который появится в директории `build`. *Примечание: убедитесь, что папка `assets` находится рядом с исполняемым файлом, либо запускайте из корня проекта, чтобы пути до текстур и музыки отработали корректно.*
