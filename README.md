## 🎮 Обзор игры

**Soul Knight Clone** — это динамичный экшен-рогалик с видом сверху (top-down shooter), вдохновленный популярной мобильной игрой Soul Knight. Игрок зачищает процедурно генерируемые комнаты от различных типов противников, собирает и меняет оружие (пистолет, пистолет-пулемет, штурмовая винтовка), прокачивает максимальное здоровье при переходе между локациями и сражается с могущественным боссом, обладающим несколькими боевыми фазами и уникальными паттернами атак.

Игра спроектирована с отказоустойчивым геометрическим рендерингом: при отсутствии растровых текстур или шрифтов движок автоматически отображает контрастные векторные примитивы, обеспечивая 100% работоспособность и стабильный FPS на любой системе.

## 🏗️ Архитектура и паттерны проектирования

### 1. Паттерн State (Машина состояний)
Управление игровыми экранами и переходами построено на классическом паттерне `State` со стековой организацией:
- `MenuState`: Главное меню игры (старт, выход, навигация клавишами).
- `PlayingState`: Основной игровой цикл (обновление физики, движение, спавн врагов, баллистика, сбор оружия, интерфейс).
- `PauseState`: Пауза (накладывается поверх игрового экрана с полупрозрачным затемнением без сброса игрового мира).
- `EndState`: Экран триумфальной победы после уничтожения финального босса.

### 2. Раздельное разрешение коллизий по осям (Wall Sliding)
Движение персонажа и врагов использует независимую проекцию смещения по осям $X$ и $Y$:
1. Персонаж смещается по оси $X$, проверяется пересечение ограничивающего параллелепипеда (AABB `sf::FloatRect`) со всеми препятствиями карты. При коллизии координата $X$ откатывается.
2. Персонаж смещается по оси $Y$, проводится аналогичная проверка.
Это устраняет классический баг залипания в стенах при движении по диагонали и обеспечивает плавное скольжение вдоль препятствий.
Скорость движения по диагонали нормализована умножением на $\frac{1}{\sqrt{2}} \approx 0.7071$.

### 3. Искусственный интеллект врагов и тактическое поведение
Враги делятся на 4 класса с уникальными характеристиками:
- **Melee (Ближний бой)**: Высокое здоровье (100 HP), агрессивное сближение с игроком на максимальной скорости и контактный урон каждые 0.5 секунды.
- **PistolEnemy (Стрелок с пистолетом)**: Дистанционный бой на средней дистанции (300 px), тактическое удержание расстояния (отступление при приближении игрока ближе $80\%$ дистанции атаки).
- **SMGEnemy (Автоматчик)**: Высокая скорострельность короткими очередями.
- **RifleEnemy (Снайпер / Винтовка)**: Дальнобойный класс (дистанция 500 px) с высоким разовым уроном (35 ед.).
- **Hard Mode**: Начиная со 2-й локации, противники получают бонус к HP (+50), увеличенный урон (+25) и повышенную на 30% скорость перемещения.

### 4. Многофазный ИИ босса (Boss Fight AI)
Битва с финальным боссом включает комплекс механик:
- **Фаза 1 (Квиз-викторина)**: Проверка знаний игрока с интерактивным выбором вариантов ответа.
- **Фаза 2 (Активный бой)**:
  - **Red Attack (Круговой обстрел)**: Радиальный залп из 8 снарядов во все стороны каждые 0.8 с.
  - **Blue Attack (Прицельный шквал)**: Фиксация позиции игрока с зарядкой мощного 50-уронного AOE-удара.
  - **Ram Attack (Таран)**: Стремительный рывок в сторону игрока с наложением эффекта оглушения (Stun на 5 секунд).
  - **Circle Aura (Аура урона)**: Постоянная пульсирующая зона вокруг босса, наносящая урон при нахождении внутри.
- **Фаза 3 (Enrage Mode, HP < 500)**:
  - **Rush Attack**: Скоростной прорыв сквозь арену с рикошетом от стен.
  - **Sweeping Beam**: Вращающийся смертоносный лазерный луч с предварительной красной предупреждающей линией.

### 5. Баллистика и механика вооружения
| Оружие | Вместимость магазина | Урон за пулю | Скорострельность | Время перезарядки |
| :--- | :---: | :---: | :---: | :---: |
| **Pistol (Пистолет)** | 20 | 20 | 0.20 с | 2.0 с |
| **SMG (Пистолет-пулемет)** | 40 | 30 | 0.10 с | 2.0 с |
| **Assault Rifle (Штурмовая винтовка)** | 30 | 34 | 0.15 с | 2.0 с |

Снаряды имеют конечный жизненный цикл (3 секунды) и мгновенно деактивируются (`expire()`) при попадании в препятствие, врага или игрока.

## 🚀 Инструкция по сборке и запуску

### Сборка на Linux (Ubuntu / Debian)

1. Установите компилятор, CMake и библиотеку SFML 3:
   ```bash
   sudo apt-get update
   sudo apt-get install -y build-essential cmake libsfml-dev
   ```

2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/DanislonZombovich/SoulKnightCloneGame.git
   cd SoulKnightCloneGame
   ```

3. Скомпилируйте проект:
   ```bash
   mkdir build && cd build
   cmake ..
   cmake --build .
   ```

4. Запустите игру:
   ```bash
   ./SoulKnightClone
   ```

### Сборка на Windows (CMake + MinGW / MSVC)

1. Установите [CMake](https://cmake.org/download/) и [SFML 3](https://www.sfml-dev.org/download/sfml/3.0.0/).
2. Если SFML распакован в `C:/SFML-3.1.0`, CMake найдет его автоматически. Либо передайте путь при генерации проекта:
   ```cmd
   mkdir build
   cd build
   cmake .. -DSFML_DIR="C:/Path/To/SFML-3.x/lib/cmake/SFML"
   cmake --build . --config Release
   ```
3. Исполняемый файл `SoulKnightClone.exe` появится в директории `build` (все необходимые `.dll` библиотеки копируются автоматически).

### Сборка на macOS

1. Установите SFML через Homebrew:
   ```bash
   brew install sfml cmake
   ```
2. Сборка и запуск:
   ```bash
   mkdir build && cd build
   cmake ..
   cmake --build .
   ./SoulKnightClone
   ```

## ⚡ Произведенные оптимизации и улучшения

В рамках ревизии исходного кода были устранены следующие критические проблемы:
1. **Кроссплатформенная сборка**: `CMakeLists.txt` избавлен от жесткой привязки к путям Windows `C:/SFML-3.1.0` и безусловного копирования `.dll` на Unix-системах. Проект теперь собирается "из коробки" на Linux, macOS и Windows.
2. **Оптимизация рендеринга UI**: Устранено регулярное обращение к диску `font.openFromFile()` на каждом кадре внутри `UI::draw()`, приводившее к микрофризам и падению FPS. Шрифт загружается единожды в конструкторе `UI`.
3. **Плавное скольжение по стенам (Wall Sliding)**: Разделена проверка коллизий по осям $X$ и $Y$ для игрока, что исключило мертвое залипание при движении в угол или по диагонали.
4. **Нормализация диагональной скорости**: Добавлена компенсация скорости при одновременном нажатии двух клавиш направления ($W+D$), уравняв диагональную скорость с ортогональной.
5. **Поддержка стрелок клавиатуры**: Добавлена возможность управления как через `WASD`, так и через стрелки `↑ ← ↓ →`.
6. **Оптимизация баллистики**: Метод `Projectile::expire()` теперь мгновенно деактивирует попавшие пули, предотвращая фантомные коллизии снарядов в точке `(0,0)`.
